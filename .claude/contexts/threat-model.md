# localsend-fork 威胁模型（审查上下文）

## 资产
- 用户文件（传输中、保存到下载目录）
- 设备身份（指纹、alias）
- PIN / 自动化 PIN

## 信任边界
- **入**：同 LAN 任意设备的 HTTP（53317）、UDP 多播发现包、接收到的文件名/路径
- **出**：发送到其他设备的请求、写本地文件系统

## 关键不变量（必须有测试守护）
1. upload 必须三参齐全 + sessionId 匹配 + token 匹配 + 来源 IP 匹配
2. 文件保存路径不得逃逸目标目录
3. PIN 比较恒定时间
4. 随机源 = `Random.secure()` / UUID v4
5. 错误响应不泄露期望值

## 范围外
- Rust FFI 内存安全（多为 frb 生成，单独评估）
- 跨设备端到端协议（手动测试清单）
